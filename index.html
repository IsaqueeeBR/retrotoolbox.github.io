How to insert a model - Open a place in Roblox Studio. On the top bar, click Insert, then select Import Model. Paste the model ID into the field and import it.
How to export a model - Open a place in Roblox Studio and select the model you want to export. On the top bar, click Insert, then select Export Model. Wait for the export process to finish. Once the ID appears, that is your model ID.
